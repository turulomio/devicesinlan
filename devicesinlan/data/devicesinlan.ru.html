NAME

devicesinlan: Сканирует все устройства в локальной сети (LAN). Вы можете задать псевдонимы известным устройствам для обнаружения посторонних устройств.

SYNOPSIS

devicesinlan [-h] [--version] [--method {PingArp,ScapyArping,Scapy}] [--interface INTERFACE | --add | --remove | --list | --load LOAD | --save SAVE | --reset] [--debug DEBUG]

ОПИСАНИЕ

        Если запустить DevicesInLan без параметров, запустится мастер консоли.

        Также можно использовать один из следующих параметров.

        --interface

                Сканирует сеть выбранного интерфейса и выводит список обнаруженных устройств.

                Неизвестные устройства отображаются красным цветом. Зеленым отмечены доверенные устройства.

        --add

                Позволяет добавить известное устройство через консоль.

        --remove

                Позволяет удалить известное устройство через консоль.

        --list

                Отображает все известные устройства из базы данных в консоли.

        --load

                Загружает список известных устройств в формате XML.

        --save

                Сохраняет список известных устройств в XML-файл.

        --debug

                Выводит отладочную информацию при работе DevicesInLAN. По умолчанию отключено

                Параметр может принимать значения: CRITICAL, ERROR, WARNING, INFO, DEBUG.

        --reset

                Удаляет все известные устройства.

МЕТОДЫ СКАНИРОВАНИЯ

        DevicesInLan поддерживает несколько методов сканирования. Добавьте --method в режиме консоли.

        PingArp

                Пытается установить сокет-соединение с каждым устройством в LAN, затем получает MAC с помощью команды 'arp'

                Метод PingArp используется по умолчанию в Windows и Linux.

        Scapy

                Использует Scapy для отправки ARP-запросов и получения MAC-адресов каждого IP в подсети.

                Этот метод доступен в Windows и Linux, но требует прав администратора.

                Кроме того, в Windows необходимо установить 'npcap'.

        ScapyArping

                Использует функцию arping из Scapy для отправки ARP-запросов и получения информации о MAC-адресах.

                Этот метод доступен в Windows и Linux, но требует прав администратора.

                Кроме того, в Windows необходимо установить 'npcap'.

ПРИМЕРЫ

        devicesinlan

                Команда по умолчанию. Использует метод PingArp.

        devicesinlan --method ScapyArping

                Использует метод ScapyArping.
